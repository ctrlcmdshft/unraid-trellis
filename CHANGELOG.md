## [1.0.0] - 2026-09-20

### Added

- Production-ready Unraid version-2 XML template.

- Port `8477`, WebUI link, and `unless-stopped` restart policy.
- Docker Compose example, community icon, validation workflow, and issue forms.
- Clear licensing, upstream, support, and non-affiliation notices.
