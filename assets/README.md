# Community icon

`trellis-community.svg` and its rendered PNG are original artwork for this unofficial Unraid integration. The abstract lattice and container outline are generic and intentionally avoid official Trellis or Strand branding.

The Unraid template uses the raw GitHub URL for the 512×512 PNG. Keep that filename stable. If replacing the artwork, use only artwork you own or have explicit permission to distribute, retain an editable source, and avoid any design that implies official status or endorsement.
